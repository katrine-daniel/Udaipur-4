# Udaipur Travel Blog — Page 04

A responsive, SEO-focused travel blog page about Udaipur, built with Tailwind CSS. Part of a 4-page Udaipur series.

**Live demo:** https://katrine-daniel.github.io/Udaipur-4/

## Features

- Hero banner with article headline
- Long-form article layout with images and highlighted tips
- Sidebar and call-to-action blocks
- Mobile-first, responsive typography

## Tech stack

HTML5, Tailwind CSS (CDN)

## Run locally

No build step. Clone the repo and open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
